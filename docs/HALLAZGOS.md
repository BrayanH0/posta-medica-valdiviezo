# Hallazgos (diagnóstico del software inicial)

Diagnóstico de la línea base LB-0. Los IDs (H-001, H-002, …) son permanentes: se citan en las solicitudes de cambio (RFC) y no se renumeran.

**Gravedad:** Crítica / Alta / Media / Baja.

**Tipo de mantenimiento** (clasificación del curso):
- **Correctivo:** corrige un error que ya ocurre.
- **Preventivo:** no hay falla, pero mejora la mantenibilidad (duplicación, mala estructura, falta de principios SOLID).
- **Adaptativo:** adapta el sistema a un cambio del entorno.
- **Perfectivo:** agrega o mejora una funcionalidad.

Rutas abreviadas: `FE/` = `proyecto_valdiviezo/src/app/`, `BE/` = `backend/backend/src/main/java/com/centro_valdiviezo/backend/`.
